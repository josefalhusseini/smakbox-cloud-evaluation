Molnstrategi & Utvärdering

Rekommendation av molnplattform för Smakbox AB kundportal

Presenteras av Josef Alhusseini och Kevin Hermansson

Smakbox AB — Krav & Utmaningar

  • Hög belastning på fredagar (10:00–14:00): Kunderna lägger alla veckobeställningar samtidigt. Systemet måste kunna skala upp automatiskt.
  • Minimalt driftsansvar: Företaget saknar ett eget driftteam. Molnleverantören måste ansvara för operativsystem och serverunderhåll (PaaS-fokus).
  • GDPR & Lagring: 50 GB lagring för receptbilder (JPEG) och recepthäften (PDF). All data måste sparas inom EU (helst Sverige).
  • Budget: Max 500 € / månad (ca 5 800 SEK).

Arkitektur i Microsoft Azure

  • Webbportal: App Service (Standard S1, Linux)
    • Hanterar driftsmiljön utan serverunderhåll.
    • Autoskalning: 1 instans normalt, skalar till 3 på fredagar.
  • Fillagring: Blob Storage (Hot Tier, ZRS)
    • 50 GB receptbilder och PDF-häften med zon-redundans.
  • Databas: Azure SQL Database (Serverless Gen5)
    • Skalar datorkraft (0,5–2 vCores) utifrån belastning.
    • Auto-pause aktiverat vid inaktivitet.
  • Region: Sweden Central (Gävle/Sandviken)
    • 100% dataresidens på svensk mark.

Slutsats & Rekommendation — Varför Azure över AWS?

Huvudrekommendation: Microsoft Azure (~170,62 €/mån)

  • Minimalt driftsansvar (Ren PaaS): Smakbox saknar ett eget IT-driftteam. Azure sköter all underliggande nätverks- och serverinfrastruktur så att Smakbox kan fokusera helt på sin applikationskod.
  • Äkta Serverless Auto-pause: Azure SQL pausas automatiskt ned till 0 kr i beräkningskostnad under helger och nätter när inga beställningar görs.
  • Billigare i längden (Sparar arbetstid): Prisskillnaden är cirka 95 €/månad. Att lägga bara 1 timme i månaden på serverunderhåll i AWS kostar mer än så. Med 170 €/månad ligger vi ändå långt under budgeten (500 €/månad).
  • GDPR & Svensk dataresidens: 100 % lokal datalagring i Sweden Central (Gävle/Sandviken).

Alternativt Spår: AWS (~75,80 €/mån)

  • Mer infrastrukturkonfiguration: AWS ger en lägre renodlad månadskostnad, men kräver manuell uppsättning och underhåll av Load Balancer (ALB), Auto Scaling Groups och VPC-nätverk.
  • Kontinuerlig databas utan noll-paus: Amazon RDS PostgreSQL snurrar dygnet runt utan automatisk auto-pause vid inaktivitet.
  • GDPR & Svensk dataresidens: 100 % lokal datalagring i eu-north-1 (Stockholm).
