Målet och Utmaningarna

Smakbox AB behöver en robust kundportal för sina 200 företagskunder. Verksamhetens belastningsmönster ställer särskilda krav på infrastrukturvalen.

Fredagstoppen (Kl. 10 - 14)

Hårdaste trafiken sker under ett fåtal timmar på fredagen. Systemet måste skala ut per automatik och ta ner resurser efteråt.

GDPR & Dataresidens

All kund- och orderdata måste stanna inom EU-gränser. Driftsättning i Gävle eller Stockholm garanterar lokal lagring.

Minimal Drift (PaaS)

Inget eget ansvar för att patcha operativsystem, installera webbservrar eller konfigurera databaskluster.

Filer & Media (50 GB)

Receptbilder (JPEG) och recepthäften (PDF) som kräver tillförlitlig och billig fillagring för slutanvändare.

Budget: Max 500 € / månad

Driftskostnaderna måste hållas nere och optimeras utifrån faktisk användning.

Föreslagen Azure-arkitektur

Samtliga tjänster driftsätts i regionen Sweden Central (Gävle/Sandviken).

Webbapplikation

App Service

Standard S1 Plan

Möjliggör Auto-scaling. Skalar ut till 3 instanser automatiskt under fredagstopparna och återgår till 1 instans efteråt.

Fillagring

Blob Storage

Standard Hot, LRS

Lagrar 50 GB PDF-häften och JPEG-receptbilder. Locally Redundant Storage (LRS) är kostnadsoptimerat och tillräckligt.

Databas

Azure SQL Database

Serverless vCore

Hanterar transaktioner. Skalar datorkraft (0.5–4 vCores) steglöst vid fredagstoppen. Pausar automatiskt under inaktiva timmar.

Skalbarhetsmekanism:

Autoskalning styrs via inbyggda CPU-mätare (Web) och serverlös resursallokering (DB) helt utan mänsklig inblandning eller driftsavbrott.

AWS Motsvarigheter

Om Smakbox väljer AWS kan motsvarande lösning etableras i regionen eu-north-1 (Stockholm):

Resurs / Roll Microsoft Azure Amazon Web Services (AWS) Teknisk Kommentar
Webbapplikation App Service (Standard S1) AWS Elastic Beanstalk (eller App Runner) Driftsätter källkod direkt som PaaS. Handhar lastbalansering.
Objektslagring Blob Storage (Hot LRS) Amazon S3 Standard Högpresterande filserverlösning. Likvärdig prestanda och pris.
Relationsdatabas Azure SQL (Serverless) Amazon Aurora Serverless v2 Serverlös databasmotor som skalar resurserna dynamiskt.
Automatisk Skalning Azure Autoscale AWS Auto Scaling Skalar instanser baserat på tröskelvärden för CPU/minne.

Slutsats & Rekommendation

Svensk Dataresidens (Gävle/Sandviken)

Driftsättning i Sweden Central ger optimalt avtalsskydd och lagring på svensk mark, vilket bäst uppfyller GDPR för Smakbox och deras svenska företagskunder.

Serverlös Databasskalning

Azure SQL Serverless inbyggda auto-paus minimerar overhead på ett sätt som är mer administrativt komplext att uppnå i AWS Aurora.

Driftsenkelhet för små team

Azure Portal är mer sammanhållen för PaaS-tjänster. Smakbox sparar tid på att slippa hantera djup nätverksarkitektur (VPC/IAM) i AWS.

Trade-off: Vendor Lock-in

Genom att använda fullt hanterade PaaS-tjänster sparar Smakbox hundratals timmar i serverdrift, men bygger in sig i Azures ekosystem. Denna risk rekommenderas starkt framför manuell drift.
