Molnstrategi & Utvärdering

Rekommendation av molnplattform för Smakbox AB kundportal

Presenteras av Josef Alhusseini och Kevin Hermansson

Smakbox AB — Krav & Utmaningar

  • Hög belastning på fredagar (10:00–14:00): Kunderna lägger alla veckobeställningar under ett fåtal timmar. Systemet måste kunna skala upp automatiskt.
  • Minimalt driftsansvar: Företaget saknar ett eget driftteam. Molnleverantören måste ansvara för operativsystem och serverunderhåll (PaaS-fokus).
  • GDPR & Lagring: 50 GB lagring för receptbilder (JPEG) och recepthäften (PDF). All data måste sparas inom EU (helst Sverige).
  • Budget: Driftskostnaderna får uppgå till maximalt 500 € per månad.

Rekommenderad Arkitektur i Azure

  • Webbportal: App Service (Standard S1)
    • Hanterar driftsmiljön (PaaS) utan serverunderhåll.
    • Auto-scaling: Skalar ut till max 3 instanser under fredagstoppen.
  • Fillagring: Blob Storage (Standard Hot, LRS)
    • Kostnadsoptimerad lagring av receptbilder och PDF-filer.
  • Databas: Azure SQL Database (Serverless vCore)
    • Skalar processorkraft (0.5–4 vCores) steglöst utifrån belastning.
    • Auto-pause: Pausas automatiskt under nätter/helger för att spara pengar.
  • Region: Sweden Central (Gävle/Sandviken)
    • All lagring sker på svensk mark, vilket uppfyller GDPR.

Motsvarande Tjänster i AWS

Motsvarande uppsättning kan driftsättas i AWS-regionen eu-north-1 (Stockholm):

Behov Microsoft Azure Amazon Web Services (AWS)
Webbapplikation (PaaS) App Service (Standard S1) AWS Elastic Beanstalk (eller App Runner)
Relationell Databas Azure SQL (Serverless vCore) Amazon Aurora Serverless v2
Objektslagring (Media) Blob Storage (Standard Hot LRS) Amazon S3 Standard
Automatisk skalning Azure Autoscale AWS Auto Scaling

Månadskostnad: Azure vs AWS

Microsoft Azure (Sweden Central)
~150 €
  • App Service (S1) + Skalning: ~69 €
  • Azure SQL Serverless DB: ~76 €
  • Blob Storage (50 GB): ~1 €
  • Dataöverföring: ~4 €
AWS (Stockholm Region)
~78 €
  • Elastic Beanstalk (t3.medium + ALB): ~43 €
  • Aurora Serverless v2 DB: ~26 €
  • Amazon S3 lagring: ~1 €
  • Dataöverföring: ~8 €

Slutsats & Rekommendation

  • Val: Microsoft Azure
  • GDPR & Dataresidens: Datacentret i Gävle ger starkare garantier för lokal lagring i Sverige jämfört med AWS.
  • Kostnadskontroll: Azure SQL Serverless kan pausa till 0 vCore, vilket matchar Smakbox helgstopp bättre än AWS Aurora.
  • Strategisk Trade-off:
    • Genom att välja PaaS sparar Smakbox tid och slipper driftsansvar för servermiljön.
    • Nackdelen är en högre timkostnad och en viss *vendor lock-in* hos Microsoft. Detta bedöms dock vara ekonomiskt lönsamt för bolaget.
